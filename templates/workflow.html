Rule: After the Vendor Intake form is submitted, the Vendor Intake step is completed and the decision “touches customer data?” decides the Security path. YES → Security Approval runs at the same time as Vendor Research and then Ops Review. Manager Approval opens only after Ops Review and Security Approval are both complete. Steps

  1. LOB Requestor creates a request (this app's New request form) → Vendor Intake form.
  2. The Vendor Intake form collects details (legal name, country, website, customer data, owner, start date, purpose, pilot length). Submitting it completes the Vendor Intake step and notifies the webhook bot when one is configured.
  3. Decision “touches customer data?”: YES → Security Approval (Human) runs beside Vendor Research and Ops Review; NO → Security N/A. Research always runs.
  4. Vendor Research (GLEIF LEI check) → Ops Review (Human). Manager Approval opens when Ops Review is complete and, if the vendor touches customer data, Security Approval is complete too.
  5. Human - Manager gives final approve / reject.
