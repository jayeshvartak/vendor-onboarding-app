Vendor onboarding workflow

{{ diagram(None) }}

Rule: After Vendor Intake, the decision “touches customer data?” decides the Security path. YES → Security Approval (Human), which merges into Manager Approval (Human) — not Ops Review. NO → Security is N/A. Vendor Research → Ops Review (Human) → Manager Approval runs in every case.

Steps

  1. LOB Requestor creates a request (this app's New request form) → Vendor Intake.
  2. Vendor Intake collects details (legal name, country, website, customer data, owner, start date, purpose, pilot length).
  3. Decision “touches customer data?”: YES → also Security Approval (Human); NO → Security N/A. Research always runs.
  4. Vendor Research (GLEIF LEI check) → Ops Review (Human) → Manager Approval (Human). Security Approval merges into Manager Approval.
  5. Human - Manager gives final approve / reject.

Track progress on the Dashboard, Status lookup, and Audit trail.
